# SP Aesthetics: Find Your Ritual (demo)

A skincare quiz demo made for SP Aesthetics & Skin Clinic by Amy Conlon. It suggests a morning and evening SP.HQ Rituals routine, a collection box and a matching in-clinic facial.

- Live demo: https://amyconlon.github.io/sp-ritual-finder/
- This is a demo, not a live page. Product descriptions are placeholders until the clinic supplies its own wording.
- All settings (colours, booking link, products, boxes, facials and prices) are in the settings block near the bottom of `index.html`.
